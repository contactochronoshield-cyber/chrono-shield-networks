# THE CODE SPACES LESSON

El conocido caso de Code Spaces es una referencia importante para comprender
los riesgos de una administración centralizada sin suficientes mecanismos de
recuperación.

La lección no es simplemente "hacer backups".

Una estrategia empresarial debe considerar:

- Separación de privilegios.
- Cuentas administrativas protegidas.
- Backups aislados.
- Recovery independiente.
- Control de acceso.
- Auditoría.
- Monitoreo.
- Redundancia.

El objetivo es que la pérdida de una credencial o una cuenta administrativa no
signifique automáticamente la pérdida total de la operación.
